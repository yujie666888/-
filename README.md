# 🍅 可爱拟物番茄钟

> 拟物、简洁、可爱的番茄钟 App — 移动端优先，单文件 HTML/CSS/JavaScript

一个充满细节的番茄钟应用，拥有真实番茄造型计时器、可爱表情动画和丰富的专注辅助功能。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🍅 拟物计时器 | 真实番茄造型，茎叶、高光、阴影、陶瓷质感，圆形进度环旋转 |
| 😊 表情系统 | 眨眼、微笑、努力、休息、完成等多种可爱表情 |
| 📋 任务管理 | 增删改查今日待办，预计番茄数、标签颜色、优先级 |
| 📊 数据统计 | 今日专注时长、番茄数、连续打卡、周/月柱状图、标签分布 |
| 🌧️ 白噪音 | 雨声、咖啡馆、森林、海浪、篝火（Web Audio API 程序化生成） |
| 🏆 成就系统 | 12 个成就徽章，连续打卡、累计番茄、早起夜猫等 |
| 🎨 主题切换 | 经典番茄 / 奶油蛋糕 / 森林小屋，一键全局换肤 |
| 🌲 番茄森林 | 每完成 4 个番茄种一棵树，逐步形成可爱森林 |
| 🔔 通知提醒 | 浏览器通知、休息提醒、每日目标提醒 |
| 💾 数据持久化 | localStorage 保存所有任务、统计、成就、主题设置 |

## 🎨 配色方案

- 番茄红 `#FF6B6B`
- 奶油白 `#FFF8F0`
- 薄荷绿 `#A8E6CF`
- 浅黄 `#FFD93D`

## 🚀 使用方法

直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖。

### 快捷键

- `空格键`：开始/暂停计时

## 📱 界面预览

- **计时页面**：中央大番茄计时器，底部控制按钮（重置/开始/跳过）
- **任务页面**：任务列表，支持标签、优先级、番茄数预估
- **统计页面**：数据卡片 + 柱状图 + 标签分布图
- **我的页面**：个人卡片、主题切换、成就徽章、番茄森林、白噪音、设置

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript（零依赖）
- SVG 绘制番茄造型与进度环
- Web Audio API 生成白噪音与铃声
- localStorage 数据持久化
- CSS Variables 实现主题切换
- CSS 动画 + Web Animations API 实现粒子效果
